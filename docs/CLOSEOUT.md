# Preserved project closeout

## Project direction

Webtool development is paused as of October 5, 2026. JCFrags chose Ketch for a
separate new project. Ketch was not added to this repository. No data migration,
Sprint 2 work, LLM worker, or replacement activation is part of this closeout.
The repository is kept for records and possible later work. It is not formally
archived on GitHub.

The accepted runtime source remains
`d961aeb0407607fa3e414b5ebafc08b6c6191fe0`, delivered through PR #24.
Closeout changes on `main` are documentation only. The published
`v0.1.0-alpha.1` tag and assets remain unchanged. The Sprint 1 source is archived
as unaccepted development, not merged into the runtime and not a new release.

## Evaluation scope and result

The frozen `769d760` gate failed. One approved focused repair produced
`dc0f82a27c81f6588eeb4ed6e48fecdf0f10639f`. Its one optimized native candidate
and both opposite-order comparison rounds were consumed. Closeout used those
retained results, not another product run, fixture, retry, warmup, build, or
Bookworm compilation.

The comparison used Ketch source
`3722f58c1ff5c6b14b687ca3f925587996033536`.
Six focused runs retained 86 operations, 10 byte-identical original exports, and
complete graph and sitemap bodies for both products. The neutral packet contains
14 cases, 132 complete transformed output streams, and 46 exact original copies
in 235 files. Native schemas, parser names, and formats remain identity cues, so
blinding is limited rather than perfect.

A brand-new managed evaluator completed all 14 retained cases. The parent collected
and froze every score before the first label-key read. The parent independently
verified all 235 input hashes, 132 raw/packet stream bindings, and 344 cited quotations.
The fresh evaluator finished at 00:51:50.055 UTC on October 5. The final parent
checkpoint and phase record finished at 01:02:12.929972 UTC, before the unchanged
01:05 UTC deadline. This does not erase earlier deadline failures.

Both rounds gave these findings:

- Retained hex and MDN body content is preserved by both products. Webtool restored
  hex's Source link and Buffer's private-fields comment and nightly-only condition.
- Webtool keeps merged-table spans and header roles that Ketch loses. Webtool still
  weakens single-blockquote grouping, but keeps the quoted code and text in order.
- Webtool joins seven Buffer blanket-implementation headers as `for Twhere` rather
  than preserving the source boundary between `for T` and `where`. Ketch preserves
  that boundary. This is a material declaration-fidelity defect in both rounds.
- Webtool preserves Chemistry's Avogadro exponent, phosphate count/charge, and ten
  professional-society entries that Ketch loses. Webtool still removes scientific
  figure links and the lead montage association. Neither extraction is complete.
  Both retain the formula meanings and named Alchemy citation.
- Successful graph/sitemap bodies are equally complete. Failures are disclosed,
  not fabricated as articles. Four packet preferences for Ketch depend on masked
  Webtool Source headers. All 18 raw Webtool saved-body responses do have those
  Source lines. The parent does not count that packet-only difference as a native
  product attribution defect. The original blind scores remain unchanged.

Direct-read replay-origin references are a shared portability limit, not asserted
dead links or verified public-source access. The fresh packet preferences were
Webtool 4, Ketch 6, and 4 ties, with the workflow qualification above. These counts
are not an acceptance rule or a general product ranking.

The final candidate did not pass the complete gate. A favorable overall preference
count cannot waive a material content loss, a complete-output latency deficit, or
missing validation. No candidate integration, local activation, or Sprint 2 is
approved by this result.

### Complete-output latency

These are retained observations, not general performance guarantees. The document
cases used a warm Webtool daemon, fresh CLI processes, and cold or warm document
state. Operating-system caches were uncontrolled. Workflow walls include terminal
wait/polling, coordinator gaps, and every saved body, not just job submission.

| Material case | Ketch, seconds in rounds 1 / 2 | Webtool, seconds in rounds 1 / 2 |
|---|---|---|
| Cold Chemistry | 0.08631 / 0.08430 | 0.14423 / 0.13994 |
| Warm Chemistry | 0.02429 / 0.02514 | 0.02695 / 0.02217 |
| Cold MDN | 0.02703 / 0.02647 | 0.04354 / 0.04656 |
| Complete fresh graph, five bodies | 0.82918 / 0.82199 | 3.21212 / 3.67220 |
| Complete sitemap, four bodies | 0.82776 / 0.82394 | 3.65331 / 3.66452 |

Warm Chemistry does not show a consistent Webtool deficit. The cold Chemistry,
MDN, and complete workflow deficits recur in both orders. The fixed 0.5-second
origin spacing explains about three seconds for seven requests in the workflow
source ledger. No pacing change, polling change, or slower-crawl waiver was
approved. Persistence and partial-state disclosure have useful functions, but they
do not establish equivalent complete-output speed.

### Complete resource costs

No language-percentage target or fixed 10% resource ceiling applies. Useful output,
integration effort, and avoidable cost matter. The retained costs include the CLI,
server, helper processes, startup, idle state, binaries, runtime data, and originals.

- The optimized Webtool binaries total 86,592,720 logical bytes: CLI 16,757,872 and
  server 69,834,848. Ketch is 20,902,072 bytes. Build caches and research evidence
  are not application runtime size.
- Webtool readiness took 0.04177 to 0.05492 seconds across six holders, with
  0.03949 to 0.05257 CPU-seconds. The ready-state sample is not an exact startup
  memory high-water measurement.
- The two ten-second idle-daemon observations retained about 51.0 to 51.3 MB RSS
  and 44.5 to 44.6 MB PSS, with about 0.000066 to 0.000068 CPU-seconds. RSS is
  resident memory. PSS divides shared memory among processes. There is no separate
  idle interval receipt for the four workflow holders. Ordinary Ketch has no idle
  daemon in these cases. This does not measure its MCP mode.
- Cold Chemistry used 0.10968 to 0.11362 CPU-seconds for Ketch and 0.12938 to
  0.13443 for the complete Webtool CLI/server accounting. Sampled RSS peaks were
  about 30.6 MB and 93.7 to 94.5 MB respectively. Complete graph/sitemap work used
  about 0.00939 to 0.01059 versus 0.11244 to 0.13082 CPU-seconds, with sampled RSS
  peaks about 21.4 to 21.8 MB versus 81.3 to 82.2 MB.
- The closed document runs retained 524,497 logical bytes of Ketch runtime state
  and 1,850,397 bytes of Webtool runtime state. Webtool's 928,797 bytes of exact
  originals are included, not subtracted or charged twice. Graph and sitemap
  Webtool state retained 137,015 and 132,919 bytes respectively, including 1,847
  bytes of exact original objects. Corresponding Ketch state was 209 bytes.
  Logical and allocated-byte receipts remain separate.
- No helpers ran in these focused cases. This is not a zero-cost claim for optional
  browser, caption, document-model, or media paths.

Ten short paired operation memory comparisons are unavailable because there was
no live sample before exit. They are not zero footprint. Sampled RSS/PSS values
are lower bounds. CLI `wait4` maximum RSS remains separate. Before/after host guards
passed, but they cannot exclude every within-call burst. Binary and memory ratios
alone do not prove unnecessary bloat or acceptable cost. Full resource acceptance
remains unestablished, and the latency gate already fails.

## Cleanup and recovery boundaries

Task-owned temporary branch names and worktrees can be retired after evaluation,
verified preservation, accepted closeout documentation, and remote archive checks.
Retire duplicate build caches and temporary assessment resources only when they
contain no unique work. Keep maintained tests. Do not merge failed code to make a
branch disappear.

Preserve research data, configuration, helpers, installed binaries and receipts,
alpha assets, private candidate/build/rollback files, exact source inputs, all
historical findings, and final evaluation records. No installed service was
started or replaced for closeout. A process inspection found no project process
or listener on port 8420. That observation is not current health certification.

To inspect archived source without restoring old active branches:

```sh
git fetch origin 'refs/tags/archive/2026-10-05/*:refs/tags/archive/2026-10-05/*'
git worktree add --detach ../webtool-archived \
  archive/2026-10-05/focused-candidate
```

For exact earlier history, verify the bundle checksum, restore it into a separate
bare repository, and compare real refs plus bound pseudoref commits before use.
Do not restore over the accepted checkout or existing research data. A source
bundle does not contain ignored data, configuration, original objects, or build
assets. Their retained private records are separate recovery requirements.
